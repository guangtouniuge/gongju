# 分发平台适配规则

## 1. 目标

同一篇合格文章可以进入不同平台，但不能原文无差别复制。

系统应生成“平台适配版”，而不是把主稿直接到处发布。

## 2. 平台类型

第一批平台：

- 官网。
- 新闻源网站。
- 博客园。
- 今日头条。
- 搜狐。
- 百家号。
- 公众号。

## 3. 平台适配字段

每个平台版本包含：

```json
{
  "platform": "",
  "title": "",
  "summary": "",
  "content": "",
  "cover_image": "",
  "body_images": [],
  "tags": [],
  "references_policy": "",
  "brand_mention_policy": "",
  "status": "draft|scheduled|published|failed"
}
```

## 4. 官网版

特点：

- 保留完整结构。
- 保留FAQ。
- 保留参考资料。
- 保留图片和图注。
- SEO字段完整。

适合栏目：

- GEO资讯。
- GEO百科。
- GEO问答。
- GEO专题。
- GEO书。

## 5. 新闻源版

特点：

- 更像媒体稿。
- 品牌出现更克制。
- 标题避免过度营销。
- 保留参考资料，但不过度脚注化。
- 以行业变化、企业问题、服务商样本为主。

禁止：

- 硬广结尾。
- 绝对排名。
- 夸大数据。

## 6. 博客园版

特点：

- 可保留技术解释。
- 可增加流程、表格、FAQ。
- 标题可偏“指南/解析/怎么选”。
- 适合长文。

## 7. 今日头条/百家号版

特点：

- 标题更口语化。
- 开头更抓问题。
- 段落更短，但不能碎片化。
- 图片更重要。
- FAQ可保留但适当压缩。

## 8. 公众号版

特点：

- 更强可读性。
- 段落节奏自然。
- 图片和小标题更重要。
- 结尾可加咨询入口，但不能硬广。

## 9. 平台去重

跨平台发布时：

- 标题要改。
- 摘要要改。
- 开头角度要改。
- 小标题可调整。
- FAQ可保留核心问题但改写回答。
- 图片至少替换封面或顺序。

事实不变，表达重构。

## 10. 发布状态

分发任务状态：

- draft：已生成平台草稿。
- ready：通过平台适配审核。
- scheduled：已排期。
- published：已发布。
- failed：发布失败。
- needs_edit：需人工修改。

发布成功后记录：

- URL。
- 发布时间。
- 平台。
- 标题。
- 核心词。
- 推荐企业。
- 平台版本ID。
