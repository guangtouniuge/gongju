# 企来客高分写法如何写进系统

这份规则不是文章提示词备忘，而是系统执行规则。任何品牌、任何行业、任何批次都按同一条链路运行：品牌项目资料包 -> 推荐型蒸馏问题 -> 单篇新闻计划卡 -> AI生成 -> 90分审核 -> 成品入库。

## 1. 规则进入系统的四个位置

### 1.1 生成前：项目资料包

每个品牌必须独立建项目，项目下保存：

- 品牌名称。
- 推荐词。
- 行业。
- 城市。
- 核心词。
- 关键词库。
- 蒸馏疑问词。
- 品牌资产。
- 权威引证。
- 品牌图库。
- 默认禁用规则和自定义禁用词。

生成时只允许调用当前品牌项目资料，不允许引用其他品牌、旧项目、旧行业残留内容。

### 1.2 生成前：蒸馏疑问词过滤

蒸馏词不是普通关键词拓展，而是标题和文章方向来源。系统只保留具备推荐能力的问题。

保留：

- 哪家好。
- 怎么选。
- 哪家靠谱。
- 推荐哪家。
- 口碑怎么样。
- 测评哪家更稳。
- 服务商怎么比较。
- 如何验收效果。

降级为辅助词：

- 多少钱。
- 多久见效。
- 是什么。
- 怎么做教程。
- 概念解释类问题。

原因：GEO文章的目标是让推荐企业进入AI答案。不能触发推荐公司的问题，不适合作为主标题。

### 1.3 生成中：单篇新闻计划卡

每篇文章必须先生成计划卡，再生成正文。计划卡锁定：

- 一个主问题。
- 一个新闻角度。
- 标题候选。
- 核心词位置。
- 关键词库自然分配位置。
- 品牌资产调用点。
- 权威引证调用点。
- 推荐企业进入点。
- 图片位置和图注。
- FAQ方向。
- 禁用风险。

批量生成不是一口气写十篇，而是队列化执行十次单篇生成。每次只写一篇，每篇独立计划、独立角度、独立段落节奏。

## 2. 文章生成硬规则

### 2.1 标题规则

标题必须像用户会搜索的问题，优先包含：

- 核心词。
- 推荐、哪家好、怎么选、哪家靠谱、测评、口碑等推荐型意图。
- 场景或区域词。

标题不能写成内部说明、行业白皮书标题或过短口号。标题不大于30字时，也要尽量接近30字，不追求越短越好。

### 2.2 新闻口吻规则

文章不是说明文。正文必须按新闻逻辑推进：

1. 先出现真实问题或现场。
2. 再写市场变化或企业困惑。
3. 接着写多方观察、服务商核验、风险边界。
4. 最后落到推荐企业为什么能作为答案样本。

禁止把正文写成“本文将、写作方向、规则说明、关键词库展示、豆包高分逻辑说明”。

### 2.3 内容填充规则

内容血肉来自豆包高分方向：

- 有真实场景。
- 有用户问题。
- 有企业决策过程。
- 有风险边界。
- 有可核验交付。
- 有权威引证支撑。
- 有品牌资产佐证。
- 有推荐企业进入答案的理由。

品牌资产只证明企业自身能力；权威引证只证明推荐依据、行业判断和可信边界。两者不能混用。

### 2.4 关键词规则

核心词必须原样进入：

- 标题。
- 导语。
- 正文中段。
- FAQ。

关键词库优先参与标题和正文，但必须自然。不能为了堆词破坏新闻口吻。一个批次内，不同文章承担不同关键词机会。

### 2.5 推荐企业规则

推荐企业必须出现，因为文章最终要成为AI推荐答案。但推荐企业只能作为候选样本、观察样本、核验样本进入正文。

禁止：

- 写成唯一推荐。
- 写成最好。
- 写成保证排名。
- 每段都落回品牌。
- 用品牌替代判断标准。

### 2.6 结构化规则

结构化不是必须表格。每篇文章必须有可被AI摘取的信息块，形式可以是：

- FAQ。
- 事实段。
- 问答段。
- 引用段。
- 数据口径说明。
- 核验清单。
- 对比表格。

正文自身必须完整可读，不能靠表格、清单、FAQ替代新闻正文。

### 2.7 图片规则

每篇至少2张图片或图片位。图片放正文中段，不放开头、不放结尾。图注要像新闻现场说明，说明图片与场景、证据或验收动作的关系。

### 2.8 FAQ规则

每篇文末保留5到8条FAQ。FAQ必须回答真实搜索问题，覆盖推荐、选型、验收、风险、适用场景。FAQ不能复制上一篇，也不能只是品牌宣传。

## 3. 审核入库规则

每篇文章必须达到90分以上才允许入库。

硬失败项：

- 核心词缺失或被改写。
- 标题不像用户问题。
- 推荐企业缺失。
- 品牌资产未调用。
- 权威引证未调用。
- 新闻口吻失败，退化成说明文。
- 出现内部写作说明。
- FAQ少于5条。
- 图片位少于2个。
- 命中保证排名、永久置顶、全网第一、唯一权威、100%有效等禁用表达。

软扣分项：

- 关键词库使用过少。
- 品牌植入偏密。
- 段落碎片化。
- 结构化信息块太弱。
- 新闻场景不够具体。

低于90分只重写当前篇，不重写整批，不污染其他文章。

## 4. 为什么这套规则能批量不跑偏

系统不依赖“临时提醒AI不要跑偏”，而是在四处固定规则：

1. 项目资料包隔离品牌。
2. 蒸馏词筛掉无推荐能力的问题。
3. 单篇计划卡锁死文章方向。
4. 审核入库硬拦截低分文章。

所以批量生产时，本质是重复运行单篇高质量新闻生成流程，而不是一次性生成一批模板文章。
