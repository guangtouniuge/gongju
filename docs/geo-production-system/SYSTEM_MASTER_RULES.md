# GEO内容生产系统规则总表

## 1. 系统目标

系统要生产的是“用户搜索问题的新闻答案页”。

最终文章必须同时满足：

- 用户搜索意图明确。
- 核心词稳定命中。
- 推荐企业自然成为答案样本。
- 内容像新闻，不像说明文。
- 品牌资产与权威引证被正确使用。
- 有FAQ、图片位和可抽取信息块。
- 低于90分不入库。

## 2. 七层执行顺序

```text
第1层：品牌项目隔离
第2层：核心词与关键词库
第3层：推荐型蒸馏疑问词
第4层：品牌资产、权威引证、图库
第5层：单篇新闻计划卡
第6层：单篇标题正文一体生成
第7层：审核、重写、入库、分发
```

规则不能倒置。尤其不能先写文章再补关键词、不能先生成正文再补新闻口吻、不能没有品牌资料就生成正式批次。

## 3. 数据归属规则

品牌项目是根节点。

```text
品牌 -> 核心词
品牌 -> 关键词库
品牌 -> 蒸馏疑问词
品牌 -> 品牌资产
品牌 -> 权威引证
品牌 -> 品牌图库
品牌 -> 生成任务
品牌 -> 审核记录
品牌 -> 成品文章
品牌 -> 分发记录
```

禁止跨品牌调用数据。旧项目内容、无关行业、无关公司、污染词必须进入隔离区。

## 4. 关键词与蒸馏词规则

核心词：

- 原样保存。
- 原样进入标题、导语、正文中段、FAQ。
- 不允许换词。

关键词库：

- 在生成前参与选题、标题和正文计划。
- 每篇选择贴合主题的辅助词。
- 不合适可以不用。
- 禁止写完文章后硬塞。

蒸馏疑问词：

- 必须具备推荐公司或服务商的能力。
- 哪家好、怎么选、哪家靠谱、推荐、测评、口碑、验收类问题优先。
- 多少钱、费用、多久见效、是什么、教程类问题只做正文或FAQ辅助。

## 5. 新闻写作规则

文章必须有新闻推进：

```text
真实场景
  -> 用户问题
  -> 市场变化
  -> 企业困惑
  -> 核验标准
  -> 推荐企业样本
  -> 风险边界
  -> 行动建议
  -> FAQ
```

禁止：

- 写成规则说明。
- 写成品牌介绍。
- 写成概念教程。
- 每段两三行碎句拼装。
- 小标题只是栏目标签。
- 全篇没有人物、企业、场景、变化和判断。

## 6. 推荐企业规则

推荐企业必须出现在正文中，因为文章目标是成为AI推荐答案。

但推荐企业只能作为：

- 候选样本。
- 公开资料样本。
- 能力核验对象。
- 某类服务商代表。

不能写成：

- 唯一推荐。
- 第一名。
- 最好。
- 保证排名。
- 永久置顶。
- 包推荐、包收录、包转化。

## 7. 品牌资产与权威引证规则

品牌资产用于说明企业自身：

- 是谁。
- 做什么。
- 服务范围。
- 交付动作。
- 优势能力。
- 服务边界。
- 客户场景。

权威引证用于说明可信依据：

- 资质。
- 公开报道。
- 第三方评价。
- 行业材料。
- 平台适配证据。
- 可核验证据。

不能用品牌资产证明全行业趋势。不能把权威引证堆成说明段。不能把内部文件名写入正文。

## 8. 图片与结构化规则

图片：

- 每篇至少2张图片或图片位。
- 放正文中段。
- 图注要像新闻图注。
- 不放开头，不放结尾。

可抽取信息块：

- 每篇必须有，但形式不限。
- 可以是FAQ、事实段、问答段、引用段、数据口径、核验清单、对比表。
- 表格不是硬性要求，不能为了表格牺牲可读性。

FAQ：

- 每篇5到8条。
- 来自真实用户问题。
- 回答推荐、选型、验收、风险、适用场景。
- 不能复制上一篇。

## 9. 批量规则

批量生成不是批量写正文，而是排队执行单篇生成器。

```text
第1篇计划 -> 第1篇正文 -> 第1篇审核
第2篇计划 -> 第2篇正文 -> 第2篇审核
```

每篇必须重新选择：

- 主问题。
- 新闻角度。
- 场景。
- 辅助关键词。
- 推荐企业进入方式。
- 证据使用点。
- 图片位置。
- FAQ问题。
- 目标字数。
- 结构指纹。

连续两篇结构高度相似，暂停任务并重排计划卡。

## 10. 审核规则

低于90分不入库。

硬失败：

- 核心词缺失。
- 推荐企业缺失。
- 标题不像用户问题。
- 新闻口吻失败。
- 全篇说明文。
- 品牌资产或权威引证未调用。
- FAQ不足。
- 图片位不足。
- 出现内部规则语言。
- 出现旧项目残留。
- 出现虚假数据或虚假权威。
- 出现绝对化排名和效果承诺。

## 11. UI规则

UI是内容生产工具，不是后台表格。

左侧按生产顺序：

```text
工作台 -> 企业品牌库 -> 品牌资料库 -> 品牌文章系统 -> 品牌媒体投喂 -> AI诊断 -> 数据中心 -> 模型配置 -> 系统设置
```

每个页面必须围绕当前品牌：

```text
当前品牌
主操作按钮
当前品牌数据列表
新增/导入/编辑区
右侧状态与下一步
```

右侧面板只显示当前步骤相关质检、缺口和下一步，不放无关拼凑内容。

标题提示词、文章提示词、新闻风格和豆包高分规则默认启用，普通用户不用每次配置。

## 12. 开发验收一句话

用户必须能通过按钮真实跑通：

```text
添加品牌 -> 添加核心词并一键蒸馏 -> 拓展并保存关键词库 -> 添加品牌资产和权威引证 -> 上传图库 -> 创建任务 -> 生成文章 -> 审核 -> 入库
```

任何页面只展示不能操作，都不算完成。
