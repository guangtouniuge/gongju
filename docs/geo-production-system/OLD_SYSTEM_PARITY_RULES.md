# 对标老系统的功能与UI硬规则

这份文件用于约束 GEO 内容生产系统 1.0 的产品实现。当前系统不是重新发明后台，而是在老系统成熟操作链路基础上，增加“品牌资产、权威引证、关键词库优先调用、品牌图库、豆包高分新闻提示词、审核入库、后续分发”这些自有能力。

核心硬规则：除新增能力外，页面流程、按钮位置、列表管理、弹窗录入、任务启动、文章查看、删除和下载，都尽量对标老系统的简约操作方式。不要为了设计感制造左右分裂、无关卡片、跨流程快捷按钮或看不懂的说明区。

## 1. 总链路

系统主链路固定为：

```text
企业品牌库
  -> 关键词
  -> 关键词库
  -> 品牌知识库
  -> 品牌图库
  -> 生成任务
  -> 文章审核
  -> 成品文章库
  -> 品牌媒体投喂
```

每一步只处理当前步骤的事。不能把后续功能提前塞进当前页面，也不能让一个页面同时承担多个模块职责。

## 2. UI总规则

- 页面以列表为主体，操作按钮贴近列表或当前表单，不做无关右侧拼接。
- 顶部只保留当前模块必须按钮，不放“新建品牌、导入资料、新建生成任务”这种跨模块快捷按钮。
- 添加内容用弹窗或同页表单，保存后立刻进入本页列表，不能出现“添加区”和“展示区”完全割裂。
- 每个按钮必须真实可用：添加、编辑、查看、删除、保存、上传、生成、审核、下载都要有结果。
- 不做花哨解释卡片；说明文字只保留一句，告诉用户当前页面做什么。
- 一个品牌一套数据。所有下拉、列表、生成任务都必须跟当前品牌绑定。

## 3. 左侧导航规则

一级导航：

- 首页大屏：只看统计和流程入口。
- 企业品牌库：添加品牌项目，是所有数据根节点。
- 品牌资料库：收纳核心词、关键词库、知识库、图库。
- 品牌文章系统：统一承接生成任务、文章审核和成品文章库。
- 品牌媒体投喂：放发布和媒体分发。
- AI诊断、数据中心、模型配置、系统设置：放在生产链路后面，不干扰主流程。

品牌资料库子栏目：

- 关键词。
- 关键词库。
- 品牌知识库。
- 品牌图库。

品牌文章系统子栏目：

- 生成任务。
- 文章审核。
- 成品文章库。

禁止把“标题库”做成一级模块。标题由蒸馏词和默认标题提示词在生成任务里产生。
禁止把“写作指令”和“文章分类/批次”做成独立主流程页面。提示词是系统默认能力，批次由生成任务自然形成。

## 4. 企业品牌库

目的：新建品牌项目，作为后续所有资料的归属。

页面结构：

- 顶部：当前模块标题 + 添加品牌按钮。
- 主体：品牌列表。
- 弹窗：添加品牌。

添加字段：

- 项目名称。
- 推荐名称。
- 行业。
- 城市。

保存动作：

- 创建品牌项目。
- 当前品牌切换为新项目。
- 下一步到“关键词”页面添加核心词并一键蒸馏。

删除动作：

- 删除品牌时，同步删除该品牌下核心词、蒸馏词、关键词库、品牌知识库、品牌图库、生成任务、审核稿、成品文章和分发记录。

## 5. 关键词

目的：管理当前品牌的核心词，并查看由核心词自动生成的推荐型问题。

页面结构：

- 顶部：品牌选择 + 添加核心词。
- 主体上方：核心词列表。
- 主体下方：当前核心词的蒸馏词列表。

添加核心词弹窗字段：

- 归属项目。
- 推荐名称。
- 核心词。

保存动作：

- 保存核心词。
- 立刻生成蒸馏词。
- 蒸馏词只保留有推荐公司/服务商能力的问题。

蒸馏词保留规则：

- 保留：哪家好、哪家靠谱、怎么选、推荐哪家、口碑怎么样、测评哪家、服务商怎么比较、如何验收。
- 不作为主蒸馏词：多少钱、费用、价格、多久见效、是什么、教程、怎么操作。

删除动作：

- 删除核心词时，同步删除该核心词下所有蒸馏词和关键词库词。

禁止：

- 关键词页不出现关键词库列表。
- 关键词页不手动添加蒸馏词。
- 关键词页不做行业拓展词管理。

## 6. 关键词库

目的：围绕当前品牌和核心词，拓展行业、场景、区域、平台辅助词。关键词库是写标题和正文时的优先规则，不是强制堆词。

页面结构：

- 顶部：品牌选择 + 核心词选择 + 拓展关键词库按钮。
- 主体：关键词库列表。
- 筛选：按关键词、意图分类筛选。
- 弹窗：拓展关键词库。

拓展弹窗字段：

- 项目名称。
- 项目推荐词。
- 核心词。
- 行业。
- 拓展数量。
- 拓展词库。

按钮：

- 一键拓展。
- 保存到关键词库。

重要交互：

- 生成后的词直接进入“拓展词库”文本框，用户可以增删改。
- 不再单独做下方“候选关键词”复杂列表。
- 保存后关闭弹窗，回到关键词库列表。
- 5118接口可用时优先取接口结果，再合并系统语义拓展；接口不可用时才使用本地规则兜底。

列表字段：

- 核心词。
- 行业拓展词。
- 意图分类。
- 状态。
- 操作。

## 7. 品牌知识库

目的：保存当前品牌写作资料。1.0 不自动提炼，用户直接粘贴或导入。

页面结构：

- 顶部：品牌选择 + 添加资料。
- 主体：品牌知识库列表。
- 弹窗：添加/编辑品牌资料。

字段：

- 知识库名称。
- 品牌资产。
- 权威引证。

资料分工：

- 品牌资产：企业是谁、服务范围、优势、交付动作、案例、边界。
- 权威引证：为什么可以被推荐、资质、公开材料、平台适配、可信依据、风险边界。

写作调用规则：

- 生成时只调用当前品牌知识库。
- 正文自然体现资料，不输出“品牌资产、权威引证、参考资料、[1][2]”等内部标签。

删除动作：

- 删除知识库时，同步删除对应品牌资产和权威引证内容。

## 8. 品牌图库

目的：生成文章前准备当前品牌图片素材。1.0 是本地上传，后续再做 AI 生成图片 agent。

页面结构：

- 顶部：品牌选择 + 添加图片。
- 主体：品牌图库列表。
- 弹窗：添加图片。

字段：

- 分类名称。
- 正文用途。
- 本地图片上传。

列表操作：

- 编辑。
- 上传。
- 删除。

生成调用规则：

- 每篇至少调用2张图片或图片位。
- 图片位放正文中段，不放开头和结尾。

## 9. 生成任务

目的：启动当前品牌的文章生产。

页面结构：

- 顶部：品牌选择 + 创建生成任务。
- 主体：任务列表。
- 任务详情/进度：只显示当前任务状态，不显示文章正文。

创建任务字段必须全部来自前面已经保存的数据：

- 任务名称，系统按核心词自动生成。
- 归属品牌。
- 核心词。
- 蒸馏词总数。
- 关键词库总数。
- 品牌知识库。
- 品牌图库。
- 文章配图数量。
- 生成篇数，下拉选择。

默认规则：

- 标题提示词、正文提示词、新闻风格、审核规则默认启用。
- 普通用户不需要每次选择提示词。
- 任务弹窗只显示“默认写作规则已启用”，不让用户手动填复杂提示词。
- 除生成篇数外，任务弹窗不得要求用户临时填写文章素材；核心词、蒸馏词、关键词库、知识库、图库都必须从上游已保存数据中选择或只读展示。

执行规则：

- 一次任务可以设置多篇。
- 后台必须拆成单篇队列。
- 每篇独立计划、独立标题、独立正文、独立审核。
- 不允许一次提示词生成多篇正文。

删除动作：

- 删除任务时，应同步删除该任务下未入库文章和审核记录；已入库文章是否删除由系统弹窗确认。

## 10. 文章审核

目的：拦截低分稿，查看完整正文和失败原因。

页面结构：

- 顶部：状态筛选 + 一键审核当前批次。
- 主体：审核文章列表。
- 弹窗：审核详情。

列表字段：

- 标题。
- 文章方向。
- 核心词。
- 字数。
- 生成来源。
- 评分。
- 状态。
- 操作。

审核详情必须能看到：

- 完整正文。
- 评分。
- 核心词命中。
- 推荐词命中。
- 关键词库调用。
- 品牌资产调用。
- 权威引证调用。
- 图片位。
- FAQ。
- 禁用词/退回原因。

入库规则：

- 低于90分不能入库。
- 命中硬禁用不能入库。
- 通过后进入成品文章库。

## 11. 成品文章库

目的：只保存通过审核的文章，并支持查看、下载和分发。

页面结构：

- 顶部：全选、下载、选择分发。
- 主体上方：文章任务列表。
- 主体下方：当前任务文章列表。

任务列表：

- 一次生成任务对应一批文章。
- 点击任务后，下方只显示该任务文章。

文章列表：

- 只显示当前任务里已通过文章。
- 支持全文查看。
- 支持单篇下载。
- 支持批量下载。
- 支持删除。

下载规则：

- 下载全部：下载当前任务所有通过文章。
- 下载选中：只下载勾选文章。
- 下载本批：按任务批次导出。

## 12. 品牌媒体投喂

目的：从成品文章库选择文章，再进入官网、新闻源、B2B、自媒体等分发。

1.0 可先做待配置状态，但流程不能影响文章生产。

页面结构：

- 选择品牌。
- 选择成品文章。
- 选择平台。
- 创建分发任务。
- 查看发布状态。

## 13. 默认提示词与模型配置

默认标题提示词和默认正文提示词是系统能力，不是普通生成任务里的必填项。

模型配置页面负责：

- 大模型接口。
- 5118关键词接口。
- 小青蛙新闻源接口。
- 接口测试。

系统设置页面负责：

- 默认禁用词。
- 审核阈值。
- 图片数量底线。
- 单篇队列规则。

禁止：

- 把标题提示词单独做成业务主流程页面。
- 让用户每次生成都手动粘贴提示词。
- 因为系统配置存在，就让主流程复杂化。

## 14. 当前需要优先检查的跑通项

每次改完系统，必须从页面按钮真实跑通：

```text
清空数据
-> 添加品牌
-> 添加核心词并一键蒸馏
-> 拓展并保存关键词库
-> 添加品牌资产和权威引证
-> 上传品牌图库
-> 创建生成任务
-> 开始生成
-> 审核查看完整正文和评分项
-> 通过后进入成品文章库
-> 查看全文
-> 下载本批或单篇
```

任何一步按钮点不了、列表没刷新、数据不归属当前品牌、旧品牌残留、下载无文件、查看看不到完整正文，都算系统未跑通。
