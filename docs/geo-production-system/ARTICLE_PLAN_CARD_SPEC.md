# 文章计划卡规范

## 1. 目的

文章计划卡用于解决批量生成时最容易出现的问题：

- 多篇文章结构相同。
- 标题只是换词。
- 新闻口吻变成说明文。
- FAQ重复。
- 推荐企业切入方式重复。

系统在生成正文前，必须先生成文章计划卡。没有计划卡，不允许进入正文生成。

## 2. 计划卡字段

```json
{
  "article_id": "",
  "main_question": "",
  "title_intent": "",
  "selected_title": "",
  "news_angle": "",
  "lead_type": "",
  "reader_role": "",
  "business_scene": "",
  "selected_keywords": [],
  "must_answer_points": [],
  "section_blueprint": [],
  "brand_entry_strategy": "",
  "evidence_plan": [],
  "table_or_tool_type": "",
  "faq_plan": [],
  "image_slots": [],
  "target_length": 0,
  "difference_notes": ""
}
```

## 3. 核心字段说明

### main_question

用户真实会问的问题。

示例：

```text
西安GEO公司哪家靠谱？
连锁超市想被AI推荐，西安GEO公司怎么选？
西安豆包排名公司能不能保证排名？
```

### news_angle

本篇新闻形态。

可选：

- 企业主复盘。
- 市场调查。
- 服务商测评。
- 风险警示。
- 榜单观察。
- 口碑调查。
- 成本预算调查。
- 平台变化观察。
- 区域服务观察。
- 行业场景纪实。
- 交付验收调查。
- 负面评价澄清。
- 专家访谈。
- 数据报告。
- 现场走访。

### lead_type

开头方式。

可选：

- 企业现场。
- 用户提问。
- 平台答案异常。
- 行业会议。
- 老板复盘。
- 服务商面谈。
- 匿名案例。
- 数据变化。
- 区域场景。

### section_blueprint

不是固定目录，而是本篇段落职责。

示例：

```json
[
  {"role": "现场开头", "target_words": 320},
  {"role": "第一屏答案", "target_words": 420},
  {"role": "市场变化", "target_words": 520},
  {"role": "服务商核验", "target_words": 700},
  {"role": "推荐企业样本", "target_words": 520},
  {"role": "风险边界", "target_words": 360},
  {"role": "FAQ", "target_words": 600}
]
```

### brand_entry_strategy

推荐企业进入方式。

可选：

- 前段轻量出现，中段核验。
- 作为服务商分类样本。
- 作为公开材料案例。
- 作为问答答案中的候选。
- 作为对比表中的一项。

禁止：

- 每节收尾都出现。
- 直接写成唯一推荐。

### table_or_tool_type

本篇使用的结构化工具。

可选：

- 服务商核验表。
- 风险避坑表。
- 预算优先级表。
- 平台答案回看表。
- 区域场景匹配表。
- 合同条款检查表。
- 文章发布复盘表。
- 图片素材匹配表。

同批次不得连续复用同一种表格。

### target_length

字数目标。

规则：

- 不低于用户指定最低字数。
- 同批次不同文章字数应有差异。
- 不得为了凑字数重复观点。
- 字数由新闻计划自然决定，不由固定模板决定。

## 4. 批量计划规则

生成 10 篇时：

- 先生成 10 张计划卡。
- 每张卡角度不同。
- 每张卡标题问题不同。
- 每张卡场景不同。
- 每张卡表格类型不同或错开。
- 每张卡FAQ计划不同。
- 每张卡品牌进入方式不同。

生成 100 篇时：

- 先生成 100 张计划卡。
- 按问题类型、行业场景、新闻形态、区域、平台意图分组。
- 每 10 篇为一组，每组内部不重复。
- 每组之间允许主题相关，但结构指纹不得高度一致。

## 5. 计划卡审核

计划卡低质时，不允许进入正文。

失败条件：

- 标题不像用户问题。
- 新闻角度和上一篇相同。
- 场景为空。
- 关键词没有参与立意。
- 推荐企业没有进入策略。
- FAQ计划太泛。
- 表格类型重复。
- 目标字数完全一样。

## 6. 正文生成时的使用方式

单篇生成器只能看到：

- 当前项目档案。
- 当前文章计划卡。
- 已通过文章的结构指纹摘要。

不能看到：

- 其他文章全文。
- 未清洗参考文章正文。
- 旧项目生成内容。

这样可以减少串文、复用和内容污染。
