# geoskill 多后台 UI 框架

## 入口与页面清单

入口使用部署基础路径后的 hash，刷新与浏览器前进后退均保留页面。

| 后台 | 默认入口 | 导航与页面 |
| --- | --- | --- |
| 总后台 | `#/platform/overview` | 平台概览、代理管理、企业品牌库、模型配置、系统设置 |
| 代理后台 | `#/agency/overview` | 代理工作台、客户品牌库 |
| 项目后台 | `#/project/dashboard` | 首页大屏、企业品牌库、品牌资料库、品牌文章系统、品牌媒体投喂、AI诊断、数据中心 |

项目后台二级导航：

- 品牌资料库：关键词、关键词库、榜单服务商、品牌知识库、品牌图库。
- 品牌文章系统：生成任务、文章审核、成品文章库。

榜单服务商为现有页面，保留在资料分组；未新增独立标题库或写作指令栏目。模型配置与系统设置归入总后台。

## 页面结构与交互

深色侧栏包含 geoskill 标识、后台入口选择和分组导航。右侧依次为当前位置、当前品牌（仅项目后台）、页面标题与当前模块操作、筛选及列表。总后台与代理后台的品牌列表复用现有品牌管理；点击品牌“进入”转到项目后台关键词页，并保留选中品牌。

列表上方放添加与筛选，行末放编辑和删除；录入使用弹窗，保存后立即更新本页列表。代理列表支持名称搜索、状态筛选、全选当前结果、取消选择、批量删除确认、编辑、启停。空状态指引使用本页操作，不拼接生产流程快捷按钮。新增弹窗采用原生 dialog，支持焦点约束、Escape 关闭和取消。

## 组件复用

`src/console-ui.tsx` 提供 PageHeader、EmptyState、Modal、BatchBar、ConsoleOverview 和 AgencyDirectory。新管理页面组合这些组件；现有生产页面继续复用 SectionTitle、EditableField、SelectField 等组件，保留现有操作处理函数。

`src/console.css` 在原样式之后加载，统一边框、圆角、主次按钮、危险操作、列表表头、空状态、弹窗和键盘焦点。现有 `.panel`、`.operation-toolbar`、`.ops-table`、`.modal-head`、`.modal-actions` 等类共享新外观，无需复制页面样式。新数据表使用语义化 table 和同一组样式变量。

## 数据与范围边界

这是导航与管理交互框架，不是权限系统。三入口共用当前品牌数据；未实现登录、租户隔离或代理与项目授权关系。代理记录仅存储于本机 `geoskill.ui.agencies`，启停仅修改记录状态，不会启停登录账户。界面明确显示这一状态，不提供假账户开通。

文章审核入口连接仓库已有 Audit 组件，不改审核规则。文章计划、提示词、生成请求、入库判定与后端均不在本次改动范围，现存逻辑是否满足业务阈值需另行验收。

未访问旧系统、未修改部署配置。开发环境沿用现有 `/gongju/` 基础路径，geoskill 部署继续使用部署脚本设定的基础路径。

## 验证

- `npm run build`：类型检查与生产构建。
- `node scripts/check-console.mjs`：独立浏览器上下文中验证三入口、路由历史、代理增改与持久化、筛选、删除确认、批量删除、品牌弹窗、审核导航和窗口宽度。请求使用隔离响应，不写共享品牌状态、不调用生成 API。
- 文章生产全链路未执行：本次仅验证 UI 框架，不声称生成质量与入库规则已验收。

## 改动文件

- `src/main.tsx`：三入口路由、导航分组、顶部品牌上下文、审核入口和品牌空状态。
- `src/console-ui.tsx`：通用管理组件、代理目录与概览。
- `src/console.css`：管理界面统一样式。
- `index.html`：geoskill 页面标题。
- `scripts/check-console.mjs`：可重复运行的界面验收脚本。
- 本文：导航、复用方案与范围说明。
