# 默认禁用与审核规则

## 1. 规则结构

系统禁用规则分两层：

- 硬禁用：出现即失败，文章不能入库。
- 软预警：不一定失败，但需要扣分、提示或自动修复。

用户可以添加自定义禁用规则，但不能关闭系统硬禁用。

## 2. 硬禁用

### 2.1 绝对化宣传

禁止：

- 第一
- 最好
- 顶级
- 全网第一
- 行业第一
- 唯一权威
- 最强
- 必选

除非是引用合法、可验证的正式奖项或公开排名，并且权威引证里明确提供，否则不得使用。

### 2.2 效果保证

禁止：

- 100%有效
- 保证上榜
- 保证推荐
- 保证收录
- 包排名
- 包转化
- 永久排名
- 永久置顶
- 稳定霸屏
- 几天见效
- 一次发布长期有效

### 2.3 无依据数据

资料未提供时，禁止生成：

- 增长百分比。
- 客户数量。
- 收录数量。
- 排名位置。
- 成交金额。
- ROI。
- 复购率。
- 行业占有率。
- 覆盖平台数量。
- 服务客户数量。

允许写“部分企业反馈”“项目复盘中发现”等谨慎观察，但不能写成全行业事实。

### 2.4 伪权威

禁止虚构：

- 政府背书。
- 官方认证。
- 协会推荐。
- 红头文件。
- 媒体报道。
- 专家背书。
- 白皮书数据。
- 客户案例。
- 获奖信息。

权威引证里没有，就不能写。

### 2.5 高合规行业红线

医疗、财税、教育、金融、法律、健康、招商加盟等行业禁止：

- 根治。
- 治愈。
- 保过。
- 包就业。
- 包拿证。
- 稳赚。
- 无风险。
- 百分百节税。
- 合法避税。
- 内部渠道。
- 特殊关系。
- 监管兜底。
- 官方指定。

### 2.6 内容污染

禁止出现：

- 上一个项目的企业名称。
- 上一个行业的案例。
- 与当前项目无关的资料。
- 医疗、干细胞、疫苗、诺奖等无关残留。
- 提示词内容。
- 写作规则说明。
- 评分规则说明。
- “根据你的要求”。
- “以下是生成内容”。
- “为了提高豆包评分”。

### 2.7 结构硬伤

禁止通过：

- 字数低于2500字。
- 核心关键词缺失。
- 推荐名称缺失。
- 没有FAQ。
- 没有任何可抽取信息块，例如FAQ、引用、分题事实段、问答段、数据口径、表格或清单。
- 没有真实问题或场景。
- 没有推荐理由。
- 没有风险提示。
- 全文只有说明文口吻。
- 多篇使用同一正文骨架。

## 3. 软预警

以下问题触发扣分或自动修复：

- 品牌名称出现过多。
- 辅助关键词堆砌。
- FAQ问题重复或回答太短。
- 表格只有字段，没有可填写内容。
- 段落过碎。
- 段落过长。
- 新闻感不足。
- 可读性差。
- 权威引证使用不足。
- 品牌资产原文照搬。
- 同一概念反复解释。
- 标题不像用户问题。

## 4. 审核评分

每篇文章按 100 分审核，90 分以下失败。

评分维度：

| 维度 | 分值 | 说明 |
| --- | ---: | --- |
| 标题与用户问题 | 15 | 标题是否像真实搜索问题，是否含核心词 |
| 关键词自然度 | 15 | 核心词锁定，辅助词自然，不堆砌 |
| 新闻口吻与可读性 | 20 | 有新闻推进、段落舒适、不是说明文 |
| 场景与内容深度 | 15 | 有真实问题、案例感、行业/本地场景 |
| 推荐企业答案能力 | 15 | 推荐企业作为答案样本，非硬广 |
| 结构化抽取能力 | 10 | 有FAQ、引用、分题事实段、问答段、数据口径、表格、清单或可摘取答案块 |
| 合规与风险边界 | 10 | 无夸大、无伪权威、有适用边界 |

## 5. 审核动作

- 90分及以上：通过，可入库。
- 80-89分：自动修复一次，再复审。
- 80分以下：重写。
- 硬禁用命中：直接重写。
- 连续两次失败：转人工复核。

## 6. 批量审核

批量任务完成后，还要进行整批审查：

- 标题是否重复。
- 文章方向是否重复。
- 小标题结构是否重复。
- FAQ是否重复。
- 品牌植入句式是否重复。
- 表格类型是否重复。
- 图片位置是否重复。
- 辅助关键词是否分配过于集中。

整批重复度过高时，不能只修单篇，要回到计划卡阶段重排文章方向。
