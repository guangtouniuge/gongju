# GEO内容生产系统页面流程地图

## 1. 核心判断

系统不是“在某个页面写文章”，而是围绕一个品牌建立一条完整生产链。

正确链路：

```text
品牌库
  -> 关键词
  -> 蒸馏疑问词
  -> 关键词库
  -> 品牌知识库
  -> 品牌图库
  -> 生成任务
  -> 文章审核
  -> 成品文章库
  -> 分发中心
  -> 数据中心 / AI诊断报告
```

文章生成只能从这条链路里取数据，不能从代码里的固定演示内容、聊天上下文、旧文章或其他项目里取内容。

## 2. 数据归属规则

所有内容必须归属于品牌项目。

品牌项目是系统的根节点，至少包含：

- 品牌名称。
- 推荐词。
- 核心词。
- 行业。
- 城市。
- 关键词库。
- 蒸馏疑问词。
- 品牌资产。
- 权威引证。
- 品牌图库。
- 默认禁用规则。
- 生成任务。
- 审核记录。
- 成品文章。
- 分发记录。

禁止跨品牌调用资料。选择 A 品牌生成文章时，不能调用 B 品牌的关键词、图片、知识库、历史文章。

## 3. 左侧导航职责

### 3.1 工作台

目的：展示当前账号整体生产状态，不承载具体资料编辑。

右侧实操：

- 查看今日生成数。
- 查看待审核数。
- 查看待分发数。
- 快捷进入“添加品牌、关键词、知识库、生成任务”。

不能做：

- 不能在工作台直接写文章。
- 不能绕过品牌资料直接生成。

### 3.2 品牌库

目的：创建品牌项目，是所有资料的归属入口。

右侧实操：

- 添加品牌。
- 填写品牌名称。
- 填写推荐词。
- 填写核心词。
- 选择行业。
- 选择城市。
- 进入该品牌。

输出：

```text
当前品牌项目
```

后续所有页面都必须带着当前品牌项目运行。

### 3.3 关键词

目的：为当前品牌添加核心词，并查看自动生成的蒸馏疑问词。

右侧实操：

- 选择品牌。
- 添加核心词。
- 添加推荐词。
- 保存核心词时自动生成蒸馏疑问词。
- 查看该品牌所有核心词。
- 点击某个核心词进入蒸馏疑问词。

输出：

```text
品牌 -> 核心词 -> 蒸馏疑问词
```

注意：

- 关键词页不管理关键词库。
- 蒸馏疑问词来自核心词自动生成，不作为主流程手动添加项。
- 核心词删除时，必须同步删除该核心词下的蒸馏词和关键词库。

### 3.4 蒸馏疑问词

目的：查看和管理由核心词页自动拓展出的用户真实搜索问题。

右侧实操：

- 选择品牌。
- 选择核心词。
- 查看自动拓展出的疑问词。
- 调用 5118 API 重新拓展疑问词。
- 批量筛选、删除、启用疑问词。
- 选择疑问词创建生成任务。

输出：

```text
品牌 -> 核心词 -> 用户问题池
```

注意：

- 蒸馏词不是主流程里的手动添加项。
- 添加核心词时必须同步生成蒸馏词。
- 蒸馏词页只承担查看、筛选、重跑拓展、创建任务。
- 蒸馏词必须具备推荐公司能力。也就是用户问完后，AI自然会推荐候选公司、品牌或服务商。
- “多少钱、费用、多久见效、是什么、教程、怎么操作”等解释型问题不进入主写作任务池，只能进入正文补充或FAQ。

疑问词示例：

- 西安GEO公司哪家靠谱？
- 西安GEO公司怎么选服务商？
- 西安豆包排名公司哪家值得推荐？
- 曲江企业做GEO该找哪类服务商？

### 3.5 关键词库

目的：围绕当前品牌和核心词，拓展行业、场景、区域、平台辅助词。关键词库参与标题和正文立意，但不是强制堆词。

右侧实操：

- 选择品牌。
- 选择核心词。
- 点击“拓展关键词库”。
- 在弹窗中查看项目名称、项目推荐词、核心词。
- 输入行业/场景词、区域词。
- 点击生成拓展词，生成结果直接进入“拓展词库”文本框。
- 用户在同一个文本框里增删改。
- 保存到关键词库列表。
- 支持按关键词和意图分类筛选。
- 支持删除单个关键词库词。

输出：

```text
品牌 -> 核心词 -> 关键词库
```

注意：

- 不单独做下方“候选关键词”复杂列表。
- 不把关键词库词当成真实企业主体。
- 正式版接 5118 API；接口不可用时只能提示接口不可用或本地模拟，不能冒充真实接口返回。

### 3.6 品牌知识库

目的：维护当前品牌的写作事实来源。

右侧实操：

- 选择品牌。
- 新建知识库。
- 添加或导入品牌资产。
- 添加或导入权威引证。
- 直接粘贴资料。
- 标记资料类型。
- 查看可用事实、待核验事实、禁用内容。

输出：

```text
品牌 -> 品牌资产包
品牌 -> 权威引证包
品牌 -> 禁用隔离内容
```

1.0 版本可以把品牌资产和权威引证放在同一个知识库页面里，但右侧操作必须是两个明确资料区：

- 品牌资产：公司介绍、服务范围、优势、交付动作、案例、服务边界。
- 权威引证：推荐理由、资质、公开报道、第三方材料、平台适配证据、可信背书。

生成时不能混用：品牌资产不能冒充第三方权威，权威引证不能被写成硬广话术。

### 3.7 品牌图库

目的：在生成文章前准备图片，文章生成时必须调用。

右侧实操：

- 选择品牌。
- 上传图片。
- 新建图片分类。
- 标注图片用途。
- 标注适合插入的位置。
- 标注行业、区域、场景。

输出：

```text
品牌 -> 图库分类 -> 图片位计划
```

图片规则：

- 每篇文章至少调用 2 张。
- 图片放正文中段。
- 不能放开头之前。
- 不能放参考资料之后。

### 3.8 默认写作规则

目的：配置系统默认提示词，不让普通用户每次手动选复杂规则。

系统内置内容：

- 标题生成规则。
- 正文生成规则。
- 新闻口吻规则。
- 豆包高分审核规则。
- 禁用词规则。
- 重写规则。

注意：

- 这是系统内置配置，不作为主流程页面。
- 默认启用，生成任务只显示“已使用默认规则”。

### 3.9 生成任务

目的：真正启动文章生产。

右侧实操必须按顺序出现：

1. 选择品牌。
2. 自动带出推荐词、核心词、行业、城市。
3. 选择核心词。
4. 选择蒸馏疑问词范围。
5. 选择关键词库范围。
6. 选择品牌知识库。
7. 选择品牌图库。
8. 选择文章批次。
9. 选择生成篇数。
10. 确认默认写作规则。
11. 点击开始生成。

生成前系统必须展示“本次调用数据包”：

```text
品牌：曝光率GEO
推荐词：曝光率GEO
核心词：西安GEO公司
关键词库：已选择若干
蒸馏疑问词：已选择若干
品牌资产：已选择
权威引证：已选择
图库：已选择
默认规则：已启用
```

生成执行方式：

```text
第1篇计划 -> 第1篇正文 -> 第1篇审核 -> 合格入库/退回
第2篇计划 -> 第2篇正文 -> 第2篇审核 -> 合格入库/退回
```

禁止一次性把 10 篇或 100 篇放进同一个大提示词里写。

### 3.11 文章审核

目的：判断生成文章是否合格。

右侧实操：

- 查看待审核文章列表。
- 打开完整正文。
- 查看评分。
- 查看扣分原因。
- 查看关键词调用。
- 查看品牌资产调用。
- 查看权威引证调用。
- 查看图片位。
- 查看 FAQ。
- 通过入库。
- 退回重写。

通过条件：

- 总分不低于 90。
- 核心词不跑偏。
- 推荐企业不缺失。
- 不出现无关项目残留。
- 不是说明文。
- 有新闻推进。
- 有 FAQ。
- 有图片位。
- 有可核验引用。

### 3.12 成品文章库

目的：只保存审核通过文章。

右侧实操：

- 查看成品文章。
- 查看完整正文。
- 按品牌、核心词、批次筛选。
- 导出 Word。
- 导出 Markdown。
- 进入分发中心。

不能做：

- 不存待审核稿。
- 不直接改生成任务。

### 3.13 分发中心

目的：把成品文章发往不同平台。

右侧实操：

- 选择品牌。
- 选择文章。
- 选择平台。
- 生成平台标题、摘要、封面图。
- 创建分发任务。
- 查看发布状态。

### 3.14 AI诊断与数据中心

目的：这是生产后的复盘区，不应放在生产链中间。

AI诊断：

- 查询品牌是否被豆包、DeepSeek等平台正确提及。
- 识别错误答案。
- 生成诊断报告。

数据中心：

- 展示生成数。
- 展示通过率。
- 展示低分原因。
- 展示分发数。
- 展示引用/收录/可见度变化。

## 4. 合格文章生成过程的数据调用

每篇文章生成时必须组装一个独立数据包：

```json
{
  "brand_project": "当前品牌",
  "recommended_word": "推荐词",
  "core_keyword": "核心词",
  "selected_question": "本篇用户问题",
  "selected_keywords": ["本篇辅助词"],
  "brand_assets": ["本篇要用的品牌事实"],
  "authority_evidence": ["本篇要用的权威事实"],
  "image_slots": ["本篇图片位"],
  "article_style": "新闻口吻",
  "audit_rules": "默认审核规则"
}
```

生成器只能读取这个数据包，不能读取页面外的临时内容。

## 5. 当前实现状态

当前 1.0 前端已经跑通最小工作流：

1. 品牌库可以新建品牌项目。
2. 关键词页可以按品牌保存核心词和关键词库。
3. 保存核心词时会同步生成蒸馏疑问词；正式版替换为 5118/5188 拓词接口。
4. 蒸馏词页只负责查看、筛选、重跑拓展和创建任务，不作为主流程手动添加入口。
5. 品牌知识库可以分区保存品牌资产和权威引证。
6. 品牌图库可以按品牌创建分类并标记正文用途。
7. 生成任务页会展示“本次调用数据包”，明确显示当前品牌、核心词、关键词库、蒸馏疑问词、品牌资产、权威引证和图库。
8. 点击开始生成后，文章进入审核页，并能查看完整正文和审核项。

后续开发重点不是再加新栏目，而是把当前本地演示数据替换为真实数据库、真实文件上传、真实 5118/5188 API 和真实大模型生成接口。

## 6. 1.0 最小可跑通标准

第一版必须做到：

1. 从品牌库新建品牌。
2. 给该品牌添加核心词，并自动拓展蒸馏疑问词。
3. 在关键词库页拓展、筛选并保存行业/场景/区域辅助词。
4. 在蒸馏词区域查看推荐型用户问题，必要时筛选或重跑拓展。
5. 给该品牌添加品牌资产和权威引证。
6. 给该品牌上传或登记图库。
7. 创建生成任务时能选择以上资料。
8. 点击开始生成后，每篇文章都显示：
   - 标题。
   - 完整正文。
   - 核心词调用。
   - 辅助词调用。
   - 推荐企业调用。
   - 品牌资产调用。
   - 权威引证调用。
   - 图片位。
   - FAQ。
   - 审核分数。
9. 低于90分不可入库。
10. 通过审核后进入成品文章库。
11. 成品文章可以进入分发中心。

这 10 条跑通后，才算系统工作流跑通。
