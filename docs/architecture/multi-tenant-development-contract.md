# geoskill 多后台开发契约

本文用于多线程开发时统一边界，避免账号、代理、项目隔离、内容生产互相覆盖。

## 开发目标

系统从单项目工具升级为三层后台：

- 总后台：管理代理、项目、模型、套餐、全局数据。
- 代理后台：管理自己名下项目、查看项目汇总和生成情况。
- 项目后台：维护资料、关键词、榜单、图库、文章生成、文章库、分发。

内容生产能力保持现有 skill 文章质量，不重写提示词。多租户改造只解决身份、权限、项目隔离、UI入口和数据归属。

## 统一角色

```text
super_admin       总后台管理员
agent             代理商
project_admin     项目管理员
project_operator  项目操作员
```

## 统一身份对象

所有服务端权限逻辑统一解析为：

```js
{
  userId,
  role,
  agentId,
  projectId,
  isSuperAdmin
}
```

临时开发阶段可从请求头读取：

- `x-geo-user-id`
- `x-geo-role`
- `x-geo-agent-id`
- `x-geo-project-id`

正式 auth 上线后，只替换 `resolveCurrentUser(req)`，不得绕开项目隔离函数。

## 数据归属字段

所有账户、项目、任务、文章、文件归属统一使用：

- `agentId`
- `projectId`
- `ownerUserId`
- `status`
- `createdAt`
- `updatedAt`

## 状态命名空间

```text
global
  系统配置、模型配置、全局套餐配置

agent:{agentId}:projects
  代理项目列表、项目汇总

project:{projectId}:state
  品牌、关键词、蒸馏词、关键词库、知识库、榜单候选、图库、任务、文章
```

兼容期允许无身份访问 legacy 数据；正式上线必须关闭 legacy anonymous。

```text
GEO_ALLOW_LEGACY_ANONYMOUS=false
```

## 线程边界

### 账号权限线

负责：

- 注册、登录、退出、修改密码。
- session/JWT 或服务端会话。
- `resolveCurrentUser(req)` 正式身份来源。
- 账号状态、密码存储、登录保护。

不得直接改：

- project scope 包装函数。
- 文章提示词。
- 内容生成流程。

### 代理项目关系线

负责：

- 总后台创建/编辑/删除/启停代理。
- 代理创建/编辑/删除/启停项目。
- `project-accounts` 注册表正式写入。
- 代理与项目关系校验。

不得直接改：

- 文章生成提示词。
- 成品文章正文逻辑。

### 后台 UI 框架线

负责：

- 总后台、代理后台、项目后台入口。
- 统一右侧卡片、表格、弹窗、批量操作、空状态。
- 角色视角下的导航菜单。

不得直接改：

- 服务端权限规则。
- 文章提示词。

### 内容系统项目化线

负责：

- 项目 scope。
- 状态隔离、文件隔离、下载隔离。
- 文章库、图库、任务、关键词、知识库只显示当前项目。
- `/api/projects/summary` 项目汇总。

不得直接改：

- 登录密码体系。
- 代理账户管理 UI。
- 文章生成提示词。

## 合并顺序

1. 内容系统项目化线先合入，因为它修复串库风险。
2. 账号权限线合入，替换临时身份来源。
3. 代理项目关系线合入，替换临时项目注册表来源。
4. UI 框架线合入，接入三层后台入口。
5. 主线程做全链路验收：登录、代理、项目、资料、生成、图库、下载、权限越权。

## 验收清单

- 未登录时不可访问正式后台。
- 总后台可看全部代理和项目。
- 代理只能看自己名下项目。
- 项目用户只能看当前项目数据。
- 项目 A 不能读取、下载、删除项目 B 的文章和图库。
- 切换项目后，品牌资料、关键词、任务、成品库全部同步切换。
- 文章生成只调用当前项目资料。
- Word 下载和图片链接带项目校验。
- 无身份 legacy 模式只用于本地兼容，正式关闭。
