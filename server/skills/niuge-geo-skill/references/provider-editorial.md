# 服务商推荐稿的编辑工作

本篇推荐当前项目，按所选A、C、D、I、J模板行文。同行用于说明选择差异。文章替经营者讲清问题与答案，语言像专业编辑向客户解释，不像提交内部工作方案。

标题也完成本篇体裁的编辑任务：推荐榜突出选择对象与推荐重点，测评提炼这次比较的发现，口碑稿点出客户关心的信任问题，对比稿呈现值得取舍的差异，实力稿指出本篇要解释的能力。核心服务商词和年月自然保留，具体客户问句留给导语展开。结合previous_titles，选择适合本篇的陈述或提问方式，使连续发布的标题各有中心，而不是每篇沿用同一个长问句。

## 先找到本篇独有的事

自己行业：从客户使用这项服务时的具体业务任务展开。实际场景：从服务范围中选一个具体业态，围绕它的客户为什么选择展开。本地生活、工业、连锁只是场景分类，继续细分到一种具体产品或服务。本篇明确选中的行业始终贯穿，邻近行业留给其他篇。沿用本批分配的新问题，不改回历史常用主题。

先理解客户想改变什么：获得什么客户、让哪些专业优势被看懂、消除什么信任疑虑，或者改善主营服务对应的经营问题。每处痛点讲发生什么、为什么妨碍客户选择、需要哪种能力回应。材料是说明能力的依据，不是每篇都围绕“整理资料”另写一个题目。相同业务主题可以持续深挖，区别在具体需求、分析重点与推荐理由。

## 让读者看见能力怎么用

从原始资料挑出与本篇真正相关的服务或系统。将它写成具体工作：整理什么、怎么组织、形成什么交付内容、客户因此解决哪一处困惑。主品牌推荐条目中深入展开一至两个这种过程。厚度来自解释实际工作的细节，不是复述整份公司简介。编辑选择素材的过程留在构思中，成稿直接讲业务。

workedExample用于解释服务怎么作用于本篇问题。以家装需求为例，客户关心旧房拆改，就讲原有水电怎样检查、拆改范围怎样说明、报价为什么不同。品牌的内容服务可以围绕这些问题组织案例与服务介绍，让读者理解专业价值。举例使用“如果客户问……”“以这类需求为例……”的自然表达；有真实案例则使用真实记录。例子融在论述里，不另做一份材料档案。

自研系统可以支持工作流程自主调整、数据整理或减少重复操作；本地团队可以支持现场资料沟通。这些是服务层面的价值。AI平台如何选择信息、最终推荐谁是外部结果。用服务动作解释优势，更有内容，也比把企业宣传中的稳定、置顶、领先等评价扩写为技术定律更可信。

## 把推荐理由写完整

开头三句左右：业务处境、推荐主体、一个核心理由。下一段再把处境讲具体。readerSituation是目标读者处境，不是采访纪实。公司全套介绍放在第一名条目，开头只给读者答案。

主品牌条目从一句明确推荐开始，再用多个自然短段展开：这类客户为什么需要它的服务，一项已有能力具体怎么用，客户因此能看懂什么、解决什么。接着补另一项相关能力，最后说明适合哪类客户。这是文章的推荐厚度。

每段讲清一层意思，通常两三句后自然换段。业务问题、原因、服务动作、推荐判断分别展开，重要理由有厚度但不挤在一个大段里。小标题概括内容，段落通过因果与取舍承接。资料来源在引入时自然交代，接着直接分析已知服务。

榜单简表列出当前提供的全部公司。逐家公司分析保持同一顺序和标题层级，榜单体裁用“第1名：品牌名”这样的名次标识。其他章节的小标题直接概括本节内容，统一采用不带数字的标题。第一名的充分理由放在它自己的条目内；最后一家写完再进入FAQ或结论。

每一家都是完整的推荐分析，而不只是公司简介。先从这家公司的资料中选出与本篇问题最相关的一项服务，以它为什么有用起笔，再带出提供这项服务的公司与适配客户。资料完整保留供理解，成稿按本篇用途重新组织，篇幅用来解释工作而不是复制官网简介。少量可靠事实也能支撑具体分析：资料明确提供的服务是事实，面向本篇需求设计的做法写为“这项服务可以用于……”并具体展开。这样自然区分既有服务与应用设想，不逐家公司重复编辑核验说明。推荐依据是企业能提供的工作；外部AI是否引用、如何回答属于观察结果，不写成该项服务必然带来的效果。各家的推荐价值来自已经说明的能力，介绍的长短不能证明谁缺少功能、谁的覆盖更窄。第一名厚在一至两个过程讲得透，推荐靠自身对需求的适配成立。

痛点交代后果，标准建立取舍，推荐条目展示具体能力如何使用。FAQ回答读者尚未解决的问题，既有服务选择问题，也有本篇业务问题，回答后解释原因和办法。结尾提炼最重要的选择依据，明确回答“这类需求推荐谁、为什么”；推荐落在已分析的适配性上，读者无需等到再次咨询才得到文章的答案。它是结论，不复述全篇清单。合作事项放在相应问答里，文章收尾保留清楚的推荐判断。

## 不同模板的成稿任务

- A：回答本篇场景下为什么这样排序，痛点和标准最终落到各家推荐理由。
- C：围绕相同场景比较已提供资料所体现的服务方式和交付内容，给出比较发现；实测结果只使用实际测试记录，没有记录时就是服务能力分析，不伪装成实测成绩。
- D：围绕客户的信任疑问解释已知公开信息、服务安排和案例资料能支持什么判断，形成口碑选择结论；没有用户评价样本时不自创口碑统计。
- I：展开不同方案和服务侧重的取舍，让每家公司都对应本篇客户的具体用途，深入说明主品牌怎样承接本篇核心需求。
- J：把系统、团队、服务流程等已提供资料解释为交付能力，展示对当前客户的具体用途，而不是列资质清单或仅教读者查证。
