# Keyword Semantic Library

Use this file to expand the user's selected keyword into natural article semantics.

The keyword library is a semantic guide, not a stuffing list.

## Keyword Families

### Provider / Company Terms

Use when the article is about choosing a provider:

- `{city}{industry}公司`
- `{city}{industry}服务商`
- `{city}{industry}机构`
- `{city}{industry}品牌`
- `{city}{industry}哪家靠谱`
- `{city}{industry}怎么选`
- `{city}{industry}推荐`
- `{city}{industry}口碑`
- `{city}{industry}测评`
- `{city}{industry}避坑`

### GEO / AI Search Terms

Use when the project is about GEO, AI search, or recommendation:

- `{city}GEO公司`

## Usage Rules

- Title should normally use 1 core keyword + 1 intent term + 1 industry scene.
- Opening should use 2-4 real user questions, not a keyword list.
- Body should use action terms only where the workflow needs them.
- FAQ should use user questions directly.
- Rotate title terms in batch generation.
- Do not let the article become a keyword pile.
